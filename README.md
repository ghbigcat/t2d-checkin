# T2D 训练打卡本

T2D 药物治疗期 30 分钟居家抗阻方案的每日打卡工具（单文件 HTML，零依赖）。

- 在线使用：<https://ghbigcat.github.io/t2d-checkin/>
- 训练方案原文：<https://ghbigcat.github.io/t2d-checkin/t2d_30.html>

打卡记录只保存在使用者的浏览器 localStorage（key: `t2d_30_checkin_v1`），不上传任何服务器。
页面内提供「导出备份 JSON / 导入备份」。

用法：在 iPhone Safari 打开首页 → 分享 → 添加到主屏幕。
